File Download
Static Files
GET /uploads/vendor-certificates/{stored-file-name} Public URL
Usage
Take fileUrl from `VendorVerifyDTO.certificates[].fileUrl` and prepend API host.
Example: https://localhost:7170/uploads/vendor-certificates/your-file.pdf
`app.UseStaticFiles()` is enabled, so files are directly downloadable.
